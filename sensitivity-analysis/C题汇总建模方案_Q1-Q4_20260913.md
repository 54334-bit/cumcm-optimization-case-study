## 二、Q1：确定性单日调度与储能价值层

**模型（两阶段词典序 LP）**

- 变量：`G_t, C_t, D_t, R_t, S_t`（kWh）
- 平衡：`G_t + E_PV_t + D_t = E_L_t + C_t + R_t`
- 递推：`S_t = S_{t-1} + 0.9·C_t − D_t/0.9`
- 约束：`0 ≤ R_t ≤ E_PV_t`；`0 ≤ C_t, D_t ≤ 833.333`；`G_t ≥ 0`；`1200 ≤ S_t ≤ 10800`；`S_0 = S_144 = 6000`
- 目标：阶段 1 `min Σ p_t·G_t`（得 `J1*`）；阶段 2 在最优值上最小化吞吐（`min Σ(C_t+D_t)`，用于唯一化并刻画套利结构）

**结果与锚点**：`J1* = 35,126.948589`、`J_actual = 35,126.948624`、`Q_G = 59,482.698915 kWh`、`Q_R = 0`（无弃电）；
无储能上界 `J0 = 48,052.046591`；晚峰净负荷 12,666.3715 kWh，其中必须购电 4,026.3715 kWh。

**论文表 1 六时段（位置对齐）**：`10:00/12:00/14:00/16:00/18:00/20:00` → `0 / 480.412450 / 0 / 445.431650 / 531.894050 / 0` kWh
（注：这六个数在旧、新两种落位口径下**恰好相同**，不能用于判别口径）。

**价值层（为 Q2/Q3 的 λ 提供依据）**：Q1 第 1 阶段 LP 的日末 SOC 等式行（`A_eq` 第 289 行 = `2T+1`）对偶 `= +0.471111`，
日初行（第 288 行）对偶 `= −0.475444`（其相反数即"初始库存边际价值"）。两者之差 `0.004333` 即"年度尺度确定套利空间近零"。

**证据**：`Q1交付\02_权威数值\q1_checkpoint.json`、`q1_sensitivity_report.json`（22 场景）、`q1_label_readback_pos.json`（六时段 ok）、

## 三、Q2：非预见 + 因果保守裕度 + 逐日 LP + E1 执行

**信息结构（假设 A1）**：题面**仅对光伏**给出预测/预报，未给负荷预报 ⇒ **当日负荷曲线视为计划阶段可得**；
光伏严格**非预见**（只用 `d` 之前的数据）。

**日前光伏预报（点预报 + 因果保守裕度）**

- `P̄_{d,t} = ¼ Σ_{j=1..4} PV_{d−j,t}`（最近 4 个连续自然日均值）
- `m_d = clip( −Q_{0.2}({ 相对误差 }_{τ∈[d−28,d)}), 0, 0.35 )`，实测均值 **7.11%**
- `P̂_{d,t} = (1 − m_d)·P̄_{d,t}`
- 分位 20% 的依据：单时段报童临界比 `4/(4+1) = 0.8`（欠购代价 4 倍差价 vs 超购 1 倍）

**计划层（逐日 LP，`K = 4` 条相同情景 ⇒ 退化为确定性 LP）**

`min Σ_t p_t·G_t + (1/K)Σ_kΣ_t 5p_t·e_{k,t} − (λ/K)Σ_k S_{k,T}`，`λ = 0.4720`

s.t. 平衡 `G_t + PV_{k,t}·dt + D_{k,t} + e_{k,t} = L_{k,t}·dt + C_{k,t} + R^{PV}_{k,t}`；
SOC 递推 `S_{k,t} = S_{k,t-1} + 0.9C_{k,t} − D_{k,t}/0.9`；界 `0 ≤ C,D ≤ 833.333`、`0 ≤ R^{PV} ≤ PV·dt`、`1200 ≤ S ≤ 10800`

**执行层 E1（用当天实际值结算，因果）**：缺口先放电、再紧急购电；富余先充电、再弃光伏、最后弃计划电 `R_G`。

**结果**：全年 **13,252,341.09 元**（计划 12,891,818.24 + 紧急 360,522.85）；紧急购电 **242 天 / 375 段 / 55,801.05 kWh**；
日界 SOC ∈ [6000, 8085.49]，年末 24:00 = 7,950 kWh（**自由终端 + λ 残值**，非硬性回 6000）。

## 四、Q3：预报递进 + 计划/调整两段承诺（读法 C）+ 执行器 v2b

**信息结构**：负荷已知（同 Q2）；光伏用**附件3 的 0/6/12/18 四次整点预报**（题面直接给定）。
附件3 语义已实证：`预报 k 小时` = 自发布时刻起第 k 个自然小时；整点值为**该小时末端采样**，
故需按 `slot_end`（整点值放该小时最后一段 + 小时内线性插值 + 首小时用当天 τ−6 版左锚 + 非负截断）**重建 144 段**。

**结算（读法 C，主口径）**：单时段现金
`p·min(G⁰,A) + 0.5p·(G⁰−A)⁺ + 1.5p·(A−G⁰)⁺ + 5p·H`
（等价：计划购电费按 `G⁰` 记账 − 取消部分净退一半 + 超出部分按 1.5 倍 + 紧急 5 倍）
读法 A（计划全额 + 附加违约金）只作**附录灵敏度**（全年 13,972,052.33 元）。

**决策与滚动**：0:00 一次性承诺全天 `G⁰`；6:00 / 12:00 / 18:00 各重优化一次，**只落定本块**（不得回溯改已执行部分）；
执行器 **v2b**：实测与计划冲突时允许**回退计划动作**（不执行"只能靠 5p 紧急电支撑"的计划充电）。

**结果**：全年 **13,120,194.06 元**；紧急购电 **42,672.2 kWh**；Δ vs v1（E1 执行器）**−1.8661%**。

**必报的三类对照**：
1. **执行器**：E1（v1）13,369,682.34 → **v2b（v2）13,120,194.06**（−1.87%）；
2. **滚动价值（题面第 7 问）**：VOI 四臂 `{0} / {0,6} / {0,6,12} / {0,6,12,18}`（见 `7.6对话\B1_VOI四组结果_20260912.md` 与图 `q3_03_rolling_value_voi`）；
3. **裕度参数化**：`q`（净需求保守度，分位标定）× `m`（额外乘性裕度）二维网格——**同参数化内** q=0.5 侧低约 0.24%，
   **禁止**写成"q=0.5 算法更优"（属参数化形状差异）。

**证据**：`交付说明_Q3_v2.md`、`01_提交件\作废声明_v0.md`（v1→v2 切换与哈希）、`03_论文素材\论文表1表2表3_四个指定日期_v2.md`、
