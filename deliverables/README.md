# Recovered delivery records

This directory preserves the question-by-question material that was manually restored after the earlier workspace loss. It is deliberately separate from the repository’s canonical public entry points.

Each `q1` through `q4` directory may contain working submission copies, methods notes, calculation code, figure variants, audit evidence, handover notes, corrections, or explicitly voided artifacts. These files are retained for traceability and recovery completeness.

Use the following locations for a clean reproduction path instead:

- `submissions/` for the five canonical workbooks;
- `src/cumcm_case_c/` for canonical source code;
- `data/processed/` for processed inputs;
- `evidence/` for frozen validation records;
- `assets/figures/` and `paper/figures/` for reusable graphics.

When a process record conflicts with a canonical artifact, the hashes and baseline described in `submissions/README.md` take precedence. A file marked `void`, `作废`, template, or draft must not be used as a final result.
