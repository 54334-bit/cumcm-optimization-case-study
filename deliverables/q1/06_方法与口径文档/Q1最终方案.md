## 0. 问题与总体判断

Q1 是确定性单日 144 个 10 分钟时段的储能日前调度：在 0:00 已知当日电价、小区负载与光伏预测，制定计划购电量与储能充放电量，满足逐时段负载、储能日初/日末电量相同，使全天外网购电费最小。

- 时间尺度：`dt = 1/6 h`，`T = 144`。
- 决策变量：`G`（购电）、`C`（充电）、`D`（放电）、`R`（弃光）、`S`（储电量），均为 kWh。
- 目标：`min J = Σ price_t · G_t`；第二目标在费用锁定下 `min H = Σ(C_t + D_t)` 消除退化同时充放电。
- 数学类别：主模型 LP；互斥兜底 MILP。不使用 pymoo/GA/DE/NSGA-II（单目标连续 LP，精确求解器可证全局最优）。

## 1. 时间口径（最终裁定：R，右端点）

附件 1 时间标签 `0:10、0:20、…、23:50、0:00+1(=24:00)` 是 10 分钟区间的**右端点**：

- `0:10` → `[00:00,00:10)`
- `0:20` → `[00:10,00:20)`
- …
- `0:00+1`(=24:00) → `[23:50,24:00)`

144 个区间恰好覆盖自然日 `[00:00,24:00)`，与题面「0:00 制定当天计划」「0:00 与 24:00 储电量相同」一致。口径 L（左端点）会漏掉 `[00:00,00:10)` 并引入次日区间，仅作敏感性，不进入主结果。

## 3. 建模（两阶段词典序 LP）

### 3.1 决策变量

`G_t`（购电，kWh）、`C_t`（交流侧充电，kWh）、`D_t`（交流侧放电，kWh）、`R_t`（弃光，kWh）、`S_t`（时段末储电量，kWh）。

### 3.2 能量平衡与储能递推

- 能量平衡：`G_t + E_PV_t + D_t = E_L_t + C_t + R_t`
- 储能递推：`S_t = S_{t-1} + 0.9·C_t − D_t/0.9`

其中 `E_L_t = Load_t · dt`、`E_PV_t = PV_t · dt`；充、放电单边效率均 0.9（往返 0.81）。

### 3.3 约束

- `0 ≤ R_t ≤ E_PV_t`
- `0 ≤ C_t ≤ Ebar`，`0 ≤ D_t ≤ Ebar`，`Ebar = 5000/6 = 833.333…`
- `G_t ≥ 0`
- `1200 ≤ S_t ≤ 10800`
- `S_0 = 6000`，`S_144 = 6000`

### 3.4 两阶段目标

- 阶段 1：`min J = Σ price_t·G_t`，严格最优记 `J1*`。
- 阶段 2：在 `Σ price_t·G_t ≤ J1* + eps_J` 下 `min H = Σ(C_t+D_t)`，正式解费用记 `J_actual`。
- `eps_J = max(1e-6, 1e-9·max(1,|J1*|))`。

## 4. 验证锚点与容差链

### 4.1 锚点

- 无储能上界：`J0 = Σ price_t·max(E_L_t − E_PV_t, 0) = 48052.046590846665` 元，须 `J1* ≤ J0`。
- 循环守恒：`Σ D_t = 0.81·Σ C_t`（对 SOC 递推求和并代入 `S_144=S_0`）。
- 晚峰下界：`LateNet = 12666.3715` kWh，先验下界 `LatePurchase ≥ 4026.3715` kWh；解后用实际 `S[108]` 重算后验下界。

### 4.2 容差链

- `E_scale_pre = max(1, S_max, Ebar, max(E_L), max(E_PV))`
- `eps_energy = max(1e-6, 1e-9·E_scale_pre)`
- `eps_soc = max(1e-6, 1e-9·S_max)`
- `eps_cost = max(1e-6, 1e-9·max(1,|J1*|))`
- `eps_mutex = eps_energy`

独立验证器（`q1_validator.py`）从解向量直接重算能量平衡残差、SOC 递推残差、循环守恒、非负与上下界、初末 SOC、费用锁定、晚峰下界、互斥，`errors=0` 才落正式结果。
