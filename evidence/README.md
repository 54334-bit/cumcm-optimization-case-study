# Validation evidence

This directory contains frozen validation outputs, audit reports, checkpoints, and sensitivity records recovered from the team workflow. They support inspection of the published results and document the assumptions used at the time.

They are historical evidence, not a substitute for running the model again in the current environment. For a fresh verification, start with `models/unified-formulation.md`, use `data/processed/` and `src/cumcm_case_c/`, then compare newly generated values with the appropriate records here.
