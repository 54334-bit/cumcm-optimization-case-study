## 二、一句话逻辑链条（论文总起句可由此改写）

四问本质上是**同一套微网物理系统**（储能 12000 kWh / 5000 kW / SOC∈[1200,10800] / η=0.9 / 禁售电 / 5 倍紧急电价）
在**四种不同设定**下的调度问题：Q1 单日两阶段、Q2 非预见+因果裕度、Q3 官方预报+滚动调整、Q4 只换波动电价。

因此"结论是否稳健"必须回答三层递进的问题：

```
① 参数层：换掉模型里的偏好参数与物理参数，结论还成立吗？
     ├─ 终端库存价值 λ（模型偏好）      → S0
     └─ 电池单程效率 η（物理参数）      → S1

② 信息层：预报质量变化会怎样传导到成本与风险？
     └─ 官方预报误差强度 ρ              → S2（离线反事实）

③ 机制层：成本变化里，有多少来自外部价格、有多少来自重新优化？
     └─ 价格环境 × 计划来源 2×2         → S3
```

三条轴**互补而不重叠**：S0/S1 问"模型自身参数变不变结论"，S2 问"信息质量值多少钱"，
S3 问"价格效应与决策效应各占多少"。三者合起来覆盖"参数—信息—环境"的完整外生扰动面。

## 三、读这些表之前必须知道的 5 条口径

1. **统一比较尺度 `J_cmp`**：`J_cmp = J_cash + λ_eval·(S_eval_start − S_eval_end)`，`λ_eval ≡ 0.4720 元/kWh`。
   λ 与 η 两个轴会改变年末库存，**只看 `J_cash` 会被"放空库存"污染**（见 `04` 的陷阱 1）。
   **论文的 λ / η 轴必须用 `J_cmp` 作主判据，`J_cash` 只作辅。**
2. **统一起点**：所有臂一律 `2025-02-01 00:00、SOC = 6000 kWh`、334 天、**无 1 月预热**。
   与四问冻结交付件完全同源——这是臂间可比性的保证。
3. **单轴**：每臂只改一个参数，其余全部冻结；`config_hash` 逐臂唯一、`raw_input_hash` 同问内唯一（已机器验证）。
4. **筛查臂**：Q3/Q4-3 的 η 只在 26 个日期上做**状态冻结局部**计算（每个日期的日初 SOC 取自基线轨迹同日值，实测 104 个 (日,臂) 对全部吻合），
   因此**只能表述为"局部机制响应"，不得写成全年稳健性**。
5. **跨问只并列**：Q2 与 Q3 的信息结构不同，二者之差**不是"改进率"**。
