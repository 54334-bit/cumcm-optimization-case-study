# 复现、验证与限制

## 可在公开仓库执行的检查

运行 `python -m pytest -q tests` 与 `python -m compileall -q src scripts tests` 可验证测试和 Python 语法。它们不证明 LP 已重跑、题面解释正确、历史数值可复现或论文已成功排版。

## 需要授权材料的检查

使用者获得题面、附件、模板及结果工作簿的合法副本后，可将其存于未纳入版本控制的本地位置，并把路径显式传给 `scripts/audit_q3_result.py`。应比对来源哈希、确认工作表结构，再独立复算费用。不要把这些材料、输出或截图提交回仓库。

## 论文限制

`paper/main.tex` 静态上是唯一论文入口，但需要外部竞赛模板与未分发的图件；因此不能在本仓库单独编译。历史源工作流曾记录过编译/审核结果，但这不等于本次重构已经重新编译或视觉验收。

## 已知限制

本仓库的 Q3 文件是经审计的代码片段，并非完整打包的端到端程序；缺少授权输入、调用模块与求解环境时不可直接产出官方格式结果。RAG 是可选方法支持，且当前检索库没有本案例的专属证据。
