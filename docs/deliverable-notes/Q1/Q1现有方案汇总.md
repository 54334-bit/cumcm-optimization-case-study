## 三、Q1 建模口径（已冻结，经三方共验）

### 3.1 时间口径：**R（右端点）**

附件 1 标签 `0:10, 0:20, …, 23:50, 0:00+1` 是 10 分钟区间的**右端点**：

```
0:10 → [00:00,00:10)     0:20 → [00:10,00:20)     …     0:00+1 → [23:50,24:00)
```

144 个区间恰好覆盖自然日，与题面「0:00 制定当天计划」「0:00 与 24:00 储电量相同」一致。

### 3.2 `result1` 物化映射：**方案 A（按标签对齐 + 循环回卷）**

「计划购电量」sheet 的行标签是区间标签，其**右端点**对应附件 1 的数据点：

```
B(2+i) = G[(i+1) mod 144]
```

即 `0:10-0:20 ← G[1]`、…、`23:50-0:00+1 ← G[143]`、末行 `0:00+1-0:10+1 ← G[0]`。
**禁止**「按行序」（方案 B）：会让 result1 的 `10:00-10:10` 填成 `G[59]`，而论文表 1 同一
物理区间是 `G[60]`，触发「论文与提交文件不一致」红线。

### 3.3 变量与约束

变量：`G`（购电）、`C`（充电）、`D`（放电）、`R`（弃光）、`S`（储电量，kWh）。

```
能量平衡   G_t + PV_e,t + D_t = L_e,t + C_t + R_t
储能递推   S_t = S_{t-1} + 0.9·C_t − D_t/0.9
边界       0 ≤ G_t；0 ≤ R_t ≤ PV_e,t；0 ≤ C_t, D_t ≤ Ebar = 5000/6 = 833.333…
           1200 ≤ S_t ≤ 10800；S_0 = S_144 = 6000
```

### 3.4 目标：两阶段词典序

```
阶段 1  min J = Σ p_t · G_t                 → J1*
阶段 2  在 Σ p_t·G_t ≤ J1* + ε_J 下  min Σ(C_t + D_t)   → 消除退化同时充放电
ε_J = max(1e-6, 1e-9·max(1,|J1*|))
```

数学类别：主模型 LP（HiGHS 精确求解，可证全局最优）；互斥兜底 MILP。
**不使用** GA/DE/NSGA-II 等启发式——单目标连续 LP 无必要。

行号：`288 = 2T` 对应 `S_0 = s0`；`289 = 2T+1` 对应 `S_144 = s_T`。

### 6.2 DP 的配对关系（本次最关键的更正）

`V_0(s)` 是**初始**状态价值函数（终端 `S_144 = 6000` 固定），故其斜率 `dV_0/ds`
对应 **行 288** 那一支，**不是**行 289。三档网格独立复算：

| 网格步长 δ (kWh) | `V_0(6000)`（元） | `−dV_0/ds`（元/kWh） |
| ---: | ---: | ---: |
| 2.0 | 35136.22009233 | **0.47544444** |
| 1.0 | 35131.45656540 | **0.47544444** |
| 0.5 | 35129.24691110 | **0.47544444** |

与行 288 的边际价值一致（同一有效位），与行 289 差 3 个数量级。

### 6.3 精度口径（**不要写错**）

| 口径 | 相对 `J1*` 的残差 |
| --- | ---: |
| 离散 DP 直接解（δ=0.5） | 6.543e-05 |
| Richardson 一阶外推 | 2.524e-06 |

收敛比 2.057 / 1.9614 → 一阶收敛成立。论文写法：
**「离散 DP 在 ~2.5e-6 量级内与 LP 互证」**，**不得**写「DP 复现了 LP 最优值」；
DP 值是 LP 最优值的**上界近似**，不得当作最优成本。

### 6.4 验证链

1. **三条独立数值路径**：LP 解析对偶 / 中心差分（差 3.2e-13、2.2e-12）/ 离散 DP 斜率 —— 一致；
2. **联合扰动闭环**：`J*(6000±h, 6000±h)` 中心差分 = −0.0043333333 = 两行对偶之和（相对差 2e-10），
   **只在 Q1 模型内部成立**；
3. **可行域校验**：解析闭式 vs 暴力枚举（30 组 × 20001 点）`mismatch = 0`，
   且 `V_DP ≥ V_LP` 恒成立、差值一阶收敛 → 可行域**没有多算**；
4. **外部共验**：请神 GPT 三问全「正确」（并要求收紧命名，已采纳）；
   豆包四问全「对」；reviewer 子代理独立复算 **PASS**。

### 6.5 论文可用的三句话

1. 约束 `S_0=s0` 的对偶给出 `∂J*/∂s0 = −0.4754`，其相反数 `0.4754` 元/kWh 是初始库存的边际节省价值。
2. 约束 `S_144=s_T` 的对偶给出 `∂J*/∂s_T = +0.4711`，即日末留存要求每提高 1 kWh 的边际成本。
3. 由于 `V_0(s)` 以初始库存为自变量、日末库存固定，其斜率对应 `S_0=s0` 的对偶，
   而非 `S_144=s_T` 的对偶；离散 DP 在三档网格下给出 `−dV_0/ds = 0.475444`，与该对偶一致。

**禁止写法**：①「两行是同一状态价值的两种表示」；②「DP 状态价值斜率对应日末影子价格」；
③「0.00433 证明年度套利空间近零」（跨口径断言）。
