## 一、修订内容（一句话）

`result1.xlsx`「计划购电量」的填表口径，由
**「标签对齐 + 循环回卷」**（`B(2+i) = G[(i+1) mod 144]`）
改为 **「位置对齐」**（**`B[2+t] = G[t]`**，t = 0..143）。

```
第 2 行   = [0:00, 0:10)   <- G[0]
第 3 行   = [0:10, 0:20)   <- G[1]
  ...
第 145 行 = [23:50, 24:00) <- G[143]
```

**模板 A 列标签文字一律未动**（改标签会动模板）；只改「值与位置的对应关系」。
