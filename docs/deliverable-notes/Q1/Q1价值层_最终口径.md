## 0. 一句话结论

Q1 的价值层由**两个不同的量**构成，必须分开表述、分开配对：

| 量 | 数值（元/kWh） | 含义 | 对应 |
| --- | ---: | --- | --- |
| 行 288 对偶 `dJ*/ds0` | **−0.4754444444** | 多 1 kWh **初始**库存使当天成本**下降** 0.4754 | 初始库存 |
| ↳ 初始库存边际价值 `−dJ*/ds0` | **+0.4754444444** | 多 1 kWh 初始库存的**节省价值** | 初始库存 |
| 行 289 对偶 `dJ*/dsT` | **+0.4711111111** | 日末多存 1 kWh 使当天成本**上升** 0.4711 | 日末库存（影子价格） |
| 两者之差 | **−0.0043333333** | 日初日末同向各挪 1 kWh 的净单位成本 | 对角方向 |

**离散 DP 算的 `V_0(s)` 是初始状态价值函数，其斜率 `dV_0/ds` 只对应行 288 那一支（+0.4754），
不得与行 289（+0.4711）配对。**

## 1. 三条独立证据（全部本机可复现）

### 1.1 LP 解析对偶

`res.eqlin.marginals`（hiGHS）：

```
行 288 (2T)   S_0 = s0      → −0.47544444444444445
行 289 (2T+1) S_144 = s_T   → +0.4711111111111111
```

行结构已断言：行 288 唯一非零元在 `S_0` 列、行 289 唯一非零元在 `S_144` 列。

### 1.2 中心差分（独立于对偶的数值路径）

把对应右端项 ±1 kWh 各解一次阶段 1 LP：

```
dJ*/ds0  = −0.47544444444429246   与行 288 对偶相对差 3.2e-13
dJ*/dsT  = +0.4711111111100763    与行 289 对偶相对差 2.2e-12
```

步长敏感性 h=2/1/0.5 kWh 三档同值（见 `output/q1_value_probe.json` 的 `h_scan`）。

### 1.3 离散 DP 斜率（第三条独立路径）

DP 状态为储电量，终端 `V_144(6000)=0`、其余 `+inf`，阶段成本 `p_t·max(0, N_t+psi(x))`。
在 `s = 6000` 取 `V_0` 的左右差商：

| 网格步长 δ (kWh) | `V_0(6000)` | 相对 `J1*` | `−dV_0/ds` |
| ---: | ---: | ---: | ---: |
| 2.0 | 35136.22009233 | +2.639e-04 | **0.47544444** |
| 1.0 | 35131.45656540 | +1.283e-04 | **0.47544444** |
| 0.5 | 35129.24691110 | +6.543e-05 | **0.47544444** |

三档分辨率下 `−dV_0/ds` **精确等于行 288 的边际价值（0.4754444444）**，与行 289（0.4711）相差 6 倍于数值误差。
这从量级上决定了配对关系：**接 288，不接 289**。

### 1.4 对角方向闭环（GPT 共验要求补的验证）

直接解 `J*(6000±h, 6000±h)` 做中心差分（h = 2/1/0.5）：

```
对角导数 = −0.0043333333  =  行 288 对偶 + 行 289 对偶（相对差 2.0e-10）
```

即「两行对偶之和 = 对角方向导数」，这是 LP 灵敏度分析的直接结果，**只在 Q1 模型内部闭环**。

## 3. 论文可用的三句话（已按共验意见收紧）

1. **行 288 的语义**：约束 `S_0=s0` 的对偶给出 `∂J*/∂s0 = −0.4754`，其相反数 `0.4754` 元/kWh 是初始库存的边际节省价值。
2. **行 289 的语义**：约束 `S_{144}=s_T` 的对偶给出 `∂J*/∂s_T = +0.4711`，即日末留存要求每提高 1 kWh 的边际成本。
3. **DP 配对**：由于 `V_0(s)` 以初始库存为自变量、日末库存固定，其斜率 `dV_0/ds` 对应 `S_0=s0` 的对偶，而非 `S_{144}=s_T` 的对偶；
   离散 DP 在三档网格下给出 `−dV_0/ds = 0.475444`，与该对偶一致。

**禁止写法**：

- ✗「行 288 和行 289 是同一个状态价值的两种表示」
- ✗「DP 的状态价值斜率对应日末影子价格」
- ✗「0.00433 证明年度套利空间近零」（跨口径断言）

## 4. 数值精度口径（防止下游误判）

离散 DP 的直接解**不满足** `<1e-6`，这是离散化的固有误差，如实报告：

| 口径 | 相对 `J1*` 的残差 |
| --- | ---: |
| δ=0.5 直接解 | 6.543e-05 |
| Richardson 一阶外推 | 2.524e-06 |

* 收敛比 2.057 / 1.9614，一阶收敛成立；
* Richardson 是**外推残差估计**，不是误差上界（误差模型非纯一阶）；
* 论文写法：**「离散 DP 在 ~2.5e-6 量级内与 LP 互证」**，
  **不得**写成「DP 复现了 LP 最优值」。
