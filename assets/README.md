# Project assets

- `figures/` contains the publication figure set, manifests, and per-question figure indexes recovered from the support package.
- `paper-materials/` preserves additional manually restored paper figures, tables, and review material. It is an archival source, not the canonical figure entry point.

The 15 images referenced by `paper/main.tex` are copied into `paper/figures/` so that the stable paper source has a local figure path. Figure-generation scripts are under `src/cumcm_case_c/figures/`.
