## 四、引用与排版须知（红线）

1. 取图按本目录 `q4_figures_manifest.json` 的 `files` 字段逐张取用，**不要用通配符**。
2. **两组基线分属不同问**：Q4-2 的 2×2 基线是 Q2（13,252,341.09），Q4-3 的是 Q3 v2（13,120,194.06）。图 5 组内可比，**格值不可跨组横向比较**；①+② 分别是 +598,113.55 / +606,839.60，都不是对方的头条差。
3. **提交件 xlsx 的 SOC 只有日初/日末两点**（表 2 的「储电量」仅 00:00 与 24:00）。需要逐段 SOC 时，必须用 checkpoint 的 C/D 按 `S_{t+1}=S_t+0.9·C_t−D_t/0.9` 重建，**不要**从 xlsx 插值或用 4 小时块代替。
4. **作废数字 13,369,682.34（Q3 v1/E1）只允许出现在「已作废/对照」语境**；跨问「全天购电费」同名列含义不同（Q4 xlsx 该列 = 当日总费用，Q2 xlsx 该列 = 仅计划费），不得同轴横比。
5. 机制段的日级相关系数**分窗口**：365 天 = 0.9824，本问 334 天窗口 = 0.9801；引用时须写明窗口。
6. 图 1 的面板 (a) 用 **365 天**分位带（附件4 全量），面板 (b) 与全部费用口径用 **334 天**评估窗口，两处已在图内标注，转引时勿混。
